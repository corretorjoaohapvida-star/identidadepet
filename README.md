# Carteira de Identidade Pet

Site estatico: pagina inicial, quiz em /registro/ e acesso ao checkout Cakto.

## Deploy na Vercel

Importe este repositorio. Framework: Other. Diretorio raiz: ./. Sem comando de build. Diretorio de saida: .
A configuracao esta em vercel.json. Nenhuma variavel de ambiente e necessaria para o site atual.

## Pagamento e cadastro

Checkout: https://pay.cakto.com.br/dseki83 — taxa unica de R$ 19,90.
O cadastro fica somente no sessionStorage do navegador. Persistencia no servidor, vinculacao ao pedido, webhook e geracao/entrega automatica dos documentos ainda precisam de implementacao.

## Privacidade

Mantenha o repositorio privado. HTML, CSS, JavaScript e imagens enviados ao navegador continuam acessiveis aos visitantes do site publicado. Nunca adicione credenciais aos arquivos publicos.
